# SRM University Delhi-NCR — V4 Refined Prototype

A quick-deployment React + Vite prototype for SRM University Delhi-NCR, Sonepat.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173/`.

## Main structure

- `src/main.jsx` — Vite/React entry point
- `src/App.jsx` — page structure and prototype interactions
- `src/index.css` — visual system, responsive layout and animations
- `public/images/` — all replaceable image/logo assets
- `IMAGE_ASSETS.md` — exact image names, locations and requirements

## Image replacement workflow

Every required image has a named path already wired into the prototype. Replace the placeholder at the same path with the final image using the exact same filename.

Do not rename the files unless you also update the corresponding path in `src/App.jsx`.
